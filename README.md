# 剪贴板自动输入工具（免安装版）

按下设定好的**全局快捷键**后，自动读取剪贴板中的文本，并**模拟键盘输入**到当前焦点窗口。

本包为**免安装版**：已内置 Python 运行环境，**无需安装任何软件、无需联网**，双击即可使用。

---

## 使用方法

1. 双击 `ClipboardTyper.exe` 启动（会弹出一个黑色窗口，保持开启即可）。
2. 把鼠标焦点放到要输入的目标窗口（记事本、聊天框、编辑器等）。
3. 按下快捷键，程序就会把剪贴板里的文字“打”出来。
4. 用完后按「退出快捷键」，或直接关闭那个黑色窗口即可。

> 首次双击若弹出 Windows SmartScreen 提示，点「更多信息」→「仍要运行」即可。这是未签名程序的正常提示，不是病毒。

---

## 默认快捷键

| 功能 | 快捷键 |
| --- | --- |
| 触发输入 | `Ctrl + Shift + V` |
| 退出程序 | `Ctrl + Alt + Q` |

快捷键可在同目录的 `config.json` 中修改。

---

## 配置说明（`config.json`）

修改 exe **同目录**下的 `config.json`，改完**重新启动**程序后生效。

| 字段 | 默认值 | 说明 |
| --- | --- | --- |
| `hotkey` | `ctrl+shift+v` | 触发输入的全局快捷键 |
| `quit_hotkey` | `ctrl+alt+q` | 退出程序的快捷键 |
| `start_delay_seconds` | `0.3` | 松开修饰键后、开始输入前的额外延迟（秒） |
| `char_delay_seconds` | `0.02` | 每输入一个字符后的间隔（秒），`0` 表示不等待。有些窗口输入过快会丢字，可适当调大 |
| `mode` | `type` | `type` = 逐字模拟键盘输入；`paste` = 模拟 Ctrl+V 粘贴 |
| `trim_trailing_newline` | `true` | 是否去掉文本末尾多余的换行 |

> 如果 exe 同目录下没有 `config.json`，程序会按上表默认值运行，因此即使只拷一个 exe 过去也能用。

### 快捷键写法

修饰键与主键用 `+` 连接，不区分大小写：

- 修饰键：`ctrl`、`alt`、`shift`、`win`
- 主键：字母 `a`~`z`、数字 `0`~`9`、`F1`~`F12`、`space`、`enter`、`tab`、`esc`、方向键 `left/right/up/down` 等

示例：`ctrl+shift+f9`、`alt+f8`、`ctrl+alt+t`

---

## 两种输入模式

- **`type`（逐字输入）**：逐字模拟按键，**能正确输入中文**；输入前会自动等 Ctrl/Alt/Shift/Win 松开（避免开头字符被吞、以及回车/Tab 与修饰键组合产生多余空行/补齐），换行、Tab 用真实回车/Tab 键发送。
- **`paste`（粘贴）**：直接模拟 `Ctrl+V`。速度最快，但要求目标窗口支持粘贴。

## 常见问题

1. **按下快捷键没反应 / 提示「注册快捷键失败」**
   说明该组合键已被其他程序占用，请修改 `config.json` 中的 `hotkey`。

2. **输入到某些程序（如管理员权限运行的程序）无效**
   这是 Windows 的 UIPI（用户界面权限隔离）机制。解决办法：右键 `ClipboardTyper.exe` →「以管理员身份运行」。

3. **逐字输入太快导致丢字**
   增大 `char_delay_seconds`（例如 `0.05`），或改用 `mode: "paste"`。

4. **只想粘贴而不是逐字打**
   把 `mode` 改为 `"paste"`。

5. **多行文本出现多余空行 / Tab 触发补全**
   通常是按下快捷键时 Ctrl/Alt 还没松开造成的；程序已自动等修饰键松开后再输入。若个别程序仍有此现象，可改用 `mode: "paste"`。

6. **杀毒软件报毒**
   这是 PyInstaller 打包的未签名程序的常见误报，把本目录加入杀软白名单即可。

7. **希望开机自动启动**
   给 `ClipboardTyper.exe` 创建快捷方式，放入「启动」文件夹：按 `Win + R` 输入 `shell:startup` 回车，把快捷方式复制进去即可。
